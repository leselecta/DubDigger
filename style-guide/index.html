The design, written down

Style Guide.

Every token, component and page pattern in the Dub Digger web app, with the reasoning that put it there. Built to be read by a person and used as a lookup table by an agent, so nothing has to be re-derived from the source the next time something is added.

How to use it

The source of truth is the code, not this folder. Tokens live in web/src/styles/globals.css; components live in web/src/components/. These pages open from disk with no build step, so Tailwind cannot run here and the values below are hand-mirrored. If the two ever disagree, the code is right and this guide is the bug.

Every specimen is the real thing reproduced in plain CSS, with the Tailwind class string the app actually ships printed underneath it. Copy the string, not the stylesheet.

For fast lookup, read README.md in this folder. It is the same material as a dense table: token, value, class, where it is used. Cheaper to scan than six HTML pages when the question is only "what grey is that".

Lookup tables

The principles

Five rules sit above every token below. They come from CLAUDE.md and they are the tie-breaker when a new decision is not covered by anything on these pages.

Density comes from the ink ramp and the mono, not from crushed spacing. Four greys below ink-strong let one row carry a name, a count, a role string and a year without any of it shouting. The vertical rhythm is deliberately open: page heads at pt-16 pb-16 md:pt-24, bands at py-14, list rows at py-[18px]. Do not tighten these to fit more in.

Ranked lists over graphs, and one click to pivot. Lists sorted by strength answer "who matters here" on sight. Every artist and label is a link to its own page. Frequency is the signal, so nothing is ordered alphabetically by default.

Except where there is no page, and then it is not a link. Chip drops its href when the related id is outside the corpus. A link that pivots into a 404 is the interface claiming something it does not hold.

Show data absence honestly. "No credits recorded" must be visibly distinct from "worked alone". Never render an empty result that looks like a positive answer, and never present a weak tie as a strong one.

One question, one vocabulary. Relevance reads in the same five steps wherever it appears, with the reason for the step alongside it in grey. The search results column is the one place the word stands alone, and that is a known cost.

Hard limits

Break one of these and something else breaks with it
Limit Value What it protects
Text contrast 4.5:1 WCAG 2.1 AA, claimed in the footer in public. A new grey clears it or it is not a grey, it is a bug.
Control boundary contrast 3:1 Why a field wears edge-strong (3.08:1) and not edge (1.86:1). edge is decoration only.
Client JavaScript 19,435 B Heaviest page, of which the router is 82%. A sixth inline script needs the same argument the five made.
UI framework none Every page is .astro. React was here for a week and bought a hamburger menu and a counter for 184 KB.
Images none Discogs images are Restricted Data, not CC0. Deferred to v1.1. public/og.jpg is the site's own drawing and is not a precedent.
Third-party hosts 0 Fonts are self-hosted. No tracking, no cookies, no ads, and the footer says so.

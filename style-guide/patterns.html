Patterns

How a page is built.

Bands stacked down the column, each one a full-width rule with its contents inside 1200px. A page renders its own bands and nothing else: the shell around them is drawn once in Base.astro.

The skeleton

Base.astro Skip link → SiteHeader → <main id="content"><slot /></main> → SiteFooter → ContactDialog → scroll-hold script
Page head band column pt-16 pb-16 md:pt-24 — Eyebrow, h1, and either a lead paragraph or the count line
Identity block <dl class="mt-9 max-w-[760px]"> of FieldRows — entity pages only
Labelled bands border-t py-14, mono label left, content right — bio, relations, prose sections
List band column pt-14 pb-32 — Tabs, ListHeader, CreditRow ×n or Absence, LoadMore 
<Base
  title={`${artist.name} — Dub Digger`}
  description={description}
  pageType="ProfilePage"        // WebPage | CollectionPage | ProfilePage | AboutPage
  mainEntity={mainEntity}       // folded into the JSON-LD graph as the page's subject
  breadcrumbs={[{ name, href }]}  // Home is added for you
  noindex                       // 404 only
  search={false}                // home page only: it carries its own in the hero
>

Every page has one <main id="content"> and exactly one <h1>. On the home page the h1 is the headline, and when a query is present it is the result count instead, because that is what the page is then.

Bands span the full width, their contents stay in the column. column is 1200px with 1.5rem of gutter, 3rem from 768px up. A band that needs a rule across the viewport puts the border on the outer element and the column inside it.

State lives in the URL: ?tab=, ?sort=, ?show=, ?q=. Tabs, pagination and search are links and a plain GET form. That is what keeps a 556-row roster from being serialised into the page as JSON, and what makes every view a real address.

The canonical drops the query string, deliberately, and robots.txt disallows /*?. The tabs are the same page answering the same question, so the canonical says so.

The column heading unit stays in the heading. "Releases together" rather than "Collaborations", because the figure counts records, not partnerships: Rhett Davies and Eno are 335 here.

h1 on a results page is the count, and a miss takes the accent:
class:list={["mono-label mb-6", results.hits.length === 0 && "text-accent"]}

The search results column is the one place a grade stands alone, with no room to say what it stands on. That is a known cost of merging the two axes into one scale, not a licence to do it elsewhere.

A miss is a real answer, and the copy says why. "This corpus is a slice centred on dub techno, not all of Discogs, so plenty of real artists and labels are legitimately absent. That is the boundary working, not a gap." The same paragraph is the 404.

Folding columns

Below md the third and fourth columns drop under the name, where the header row above has no column left to name them from. So each value carries its own heading down with it and reads "Active: 2002 – 2026" on a phone.

Do

<span class="col-start-1 md:col-start-3">
  <span class="md:sr-only">Active:</span>
  2002 – 2026
</span>

Don't

<span class="col-start-1 md:col-start-3">
  <span class="md:hidden">Active:</span>
  2002 – 2026
</span>

md:sr-only, never md:hidden. ListHeader is a sibling element and cannot tell a screen reader which column it names, so display: none took the label out of the accessible tree and a row read aloud at desktop width came out "Basic Channel, 47, high, artist". Out of flow and still spoken, every value keeps the word for what it is.

The three breakpoints that carry decisions
Breakpoint What changes
sm — 640px Figures band goes to three columns. The header search field appears, and the drawer's own field disappears: each is on screen exactly where the other is not. FieldRow's label column widens from 7rem to 180px.
md — 768px Nav cells replace the drawer. The third list column unfolds. The column gutter goes 1.5rem → 3rem. LabelledBand and the footer become two columns. Page heads gain their extra top padding.
1200px The column stops growing. Not a Tailwind breakpoint, a max-width.

Spacing is Tailwind's default scale. There is no --spacing override and there should not be one. The vertical rhythm is deliberately open: the page holds a lot because most of it is quiet, not because it is small.

New page checklist

In order, for a page that has to look like it belongs.

1.  <Base title description pageType breadcrumbs> — never render SiteHeader yourself
2.  Page head band: column pt-16 pb-16 md:pt-24 → Eyebrow → one h1 → text-lead
3.  Content bands: LabelledBand for prose, or the list band for data
4.  Lists: ListHeader + CreditRow + LIST_GRID, Absence when empty, LoadMore past 40
5.  Any state (tab, sort, page, query) goes in the URL, not in a script
6.  Any pivot gets link-rule; anything with no page gets a Chip without an href
7.  Grades read in the four steps, with the reason beside them in ink-faint
8.  New grey? Check 4.5:1. New control border? edge-strong, 3:1.
9.  New script? Bind to astro:page-load, guard prefers-reduced-motion, argue the bytes
10. Numbers: toLocaleString("en-GB") and tabular-nums
